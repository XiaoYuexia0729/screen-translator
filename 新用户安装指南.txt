===================================================
    屏幕翻译器 - 新用户快速安装指南
===================================================

本指南专为首次使用的用户编写，帮助您快速安装并运行程序。

===================================================
第一步：检查 Python
===================================================

1. 按下 Win+R 键，输入 cmd，按回车打开命令提示符

2. 输入以下命令检查 Python：
   python --version

3. 如果看到 "Python 3.9.x" 或更高版本，说明已安装，跳到第二步

4. 如果提示"不是内部或外部命令"，需要安装 Python：
   - 访问：https://www.python.org/downloads/
   - 下载 Python 3.9 或更高版本
   - 安装时务必勾选 "Add Python to PATH" ✓
   - 安装完成后重新打开命令提示符测试

===================================================
第二步：安装依赖库（自动）
===================================================

1. 双击运行 run.bat

2. 程序会自动检测并安装所需的 Python 库

3. 安装过程可能需要 2-5 分钟，请耐心等待

4. 如果提示缺少 Tesseract，继续第三步

===================================================
第三步：安装 Tesseract OCR
===================================================

方式 A - 使用脚本（推荐）：

1. 双击运行 install-tesseract.bat
2. 浏览器会自动打开下载页面
3. 下载 tesseract-ocr-w64-setup-*.exe
4. 运行安装程序
5. 安装时选择 English 语言包
6. 确认安装路径为：C:\Program Files\Tesseract-OCR

方式 B - 手动下载：

1. 访问：https://github.com/UB-Mannheim/tesseract/wiki
2. 在 "Tesseract at UB Mannheim" 部分
3. 下载 Windows 64位安装程序
4. 按照提示安装（选择 English 语言包）

===================================================
第四步：启动程序
===================================================

1. 双击运行 run.bat

2. 如果一切正常，程序窗口会打开

3. 点击"鼠标选择区域"按钮

4. 在屏幕上拖动鼠标框选包含英文的区域

5. 点击"开始翻译"开始实时翻译

===================================================
验证安装（可选）
===================================================

运行 test-dependencies.bat 可以检查所有依赖是否正确安装

如果所有项显示 [OK]，说明安装成功！

===================================================
常见问题
===================================================

Q: 提示"Python 版本过低"
A: 请升级到 Python 3.9 或更高版本

Q: 提示"Tesseract not found"
A: 确认 Tesseract 安装在 C:\Program Files\Tesseract-OCR\

Q: 依赖库安装失败
A: 检查网络连接，或手动运行：
   pip install -r requirements.txt

Q: 中文显示乱码
A: 这个问题已经在程序中自动处理，无需担心

Q: 翻译失败
A: 检查互联网连接，程序需要联网使用翻译服务

Q: 程序运行但无法识别文字
A: 确保选择的区域包含清晰的英文文字（字体大小 12px 以上）

===================================================
系统要求
===================================================

操作系统：Windows 7/10/11
Python：3.9 或更高版本
网络：需要互联网连接（用于翻译）
空间：约 500MB（包括依赖库）

overlay_window.py       - 翻译显示窗口
config.py              - 配置文件
